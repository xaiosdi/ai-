# topics/ — 主题档案

每个主题一个文件，AI 按需读取。**只放敏感度低、可公开的内容**，敏感信息放私有核心仓。

## 文件模板

```markdown
---
name: 主题名
updated: YYYY-MM-DD
---

（正文，单文件控制在 500 tokens 以内，超了就拆）
```

## 建议的主题

- `technical.md` — 技术栈与技术水平（哪些熟悉 / 在学）
- `projects.md` — 重要项目档案（每个项目一小段）
- `interests.md` — 兴趣爱好
- `writing-style.md` — 如果常让 AI 代笔，放自己的文风样例
